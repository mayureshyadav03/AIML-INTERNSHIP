# 💻 AI-Assisted Coding Experiment

A Python program was created to calculate:

* Average
* Maximum
* Minimum
* Number of even numbers

The AI tools were used to understand how such a program could be generated and explained.

The generated code was then tested manually to verify that the output was correct.

### Learning

This experiment demonstrated that AI can help developers:

* Generate initial code
* Explain unfamiliar code
* Improve existing code
* Learn programming concepts faster

However, the generated code still needs to be reviewed and tested by the developer.

---

# 🐛 AI-Assisted Debugging Experiment

A deliberate error was introduced into the Python program by changing the average calculation.

The incorrect operation caused a division-by-zero error.

The error was provided to an AI tool, which was used to:

1. Identify the error.
2. Explain why the error occurred.
3. Suggest a correction.
4. Explain the corrected approach.

The corrected code was then executed and verified.

### Learning

AI tools can significantly assist with debugging by helping developers understand:

* What went wrong
* Why the error occurred
* How to correct it
* How to avoid similar errors

The developer should still verify the suggested solution by testing the code.

# 🧠 AI-Assisted Development Workflow

The experiments demonstrated the following workflow:

```text
Identify the problem
        ↓
Ask the AI for assistance
        ↓
Understand the AI response
        ↓
Review the result
        ↓
Test / Verify
        ↓
Modify if necessary
        ↓
Use the final solution
```

AI should be treated as an **assistant**, not as a replacement for human understanding and verification.

# ⚠️ Responsible Use of AI

AI-generated content should not be accepted blindly.

Important practices include:

* Verify factual information.
* Test generated code.
* Protect API keys and credentials.
* Review AI-generated content.
* Understand the solution before using it.
* Use reliable sources for important research.
* Treat AI as an assistant rather than an unquestioned authority.
