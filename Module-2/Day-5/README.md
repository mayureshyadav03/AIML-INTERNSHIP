# Expense Tracker CLI

A lightweight Python Command-Line Interface (CLI) application built to record, manage, and analyze daily expenses.

## Features
- **Add Expenses:** Input custom amounts, categories, and descriptions with input validation.
- **View Expenses:** Output records in a neatly aligned tabular layout.
- **Calculate Total:** Compute the total sum of all logged expenses instantly.
- **Category Summary:** Aggregate spending based on categories.
- **Delete Expense:** Remove specific entries safely with confirmation prompts.

## How to Run

1. Make sure Python 3 is installed.
2. Run the script using terminal/command prompt:

```bash
python main.py
